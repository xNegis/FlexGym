## Recording Rules

* Record costs in US dollars to four decimal places.
* Use the model name reported for the feature's implementation run.
* Record skipped or discontinued features when work incurred a measurable cost.
* Update a row when later implementation work is explicitly attributed to that feature; do not
  silently fold unrelated maintenance into its original cost.
